# 机场钥仓：二开方案

## 定位

机场钥仓以 SlClash 的 Mihomo/Android VPN 能力为运行底座，在上层加入 Yucon 风格的多机场账户与订阅管理。第一阶段面向 iKun 与 Pokemon 两个机场，账号信息和订阅链接由用户在应用内添加，不把任何真实订阅地址、账号或密钥写进源码。

## 代码边界

- SlClash：Mihomo core、TUN/VPN、订阅拉取、代理组、规则、后台服务和 Android 生命周期。
- Yucon：多站点账户模型、余额/流量/到期信息、签到/接口管理、加密备份和本地优先的管理思路。
- 机场适配：先抽象为标准 Clash/Mihomo 订阅；只有拿到机场官方 API 或测试接口后，才增加余额、签到等定制接口。

## 第一版页面

1. 总览：iKun / Pokemon 卡片、当前连接状态、剩余流量、到期时间。
2. 机场详情：订阅地址、更新时间、流量与到期信息、快捷刷新。
3. 节点连接：沿用 Mihomo 的代理组和节点选择能力。
4. 设置与安全：本地加密存储、备份/恢复、日志和隐私说明。
