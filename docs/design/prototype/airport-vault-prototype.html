账户仓

机场账户是订阅和签到的业务来源。

业务原则

账号、订阅和节点互相独立，错误不会级联破坏。

登录成功之后

登录不是终点，而是启动同步任务的开始。

① 保存会话Cookie / Token 进入安全存储
② 同步资料流量、到期、签到
③ 发现订阅验证格式和订阅头
④ 自动导入创建或更新 Mihomo Profile

异常时怎么办

没有订阅地址也不能让用户卡在空页面。

已登录，但暂未识别订阅地址打开机场订阅中心、重新发现订阅，或者手动粘贴链接。上一次可用配置会继续保留。
